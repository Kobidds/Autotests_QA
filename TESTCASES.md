# Позитивные тесты

## Название: Создание объявления с валидными данными  
**Предусловия:**  
Уникальный sellerId в диапазоне 111111-999999, использовался (125149).  

**Шаги:**  
1. Откройте Postman и выберите запрос "Сохранить объявления" из коллекции.  
2. Установите метод: POST.  
3. URL: `https://qa-internship.avito.com/api/1/item`  
4. В Body (raw, JSON) укажите:  
```json
{
    "sellerID": 125149,
    "name": "Andrews",
    "price": 256,
    "statistics": {
        "likes": 156,
        "viewCount": 24,
        "contacts": 99
    }
}
```  
5. Отправьте запрос.  

**Ожидаемый результат:**  
Статус-код: 200 OK.  
В ответе JSON с полем "status", краткое описание, и уникальный ID объявления.  
Объявление сохранено и может быть получено по GET-запросу с этим ID.  
```json
{
    "status": "Сохранили объявление - abfc0fbd-7e9a-4b42-8962-d7e0ea049297"
}
```

## Название: Получение существующего объявления по идентификатору.  
**Предусловия:**  
Создано объявление с известным ID.  

**Шаги:**  
1. Откройте Postman и выберите запрос "Получить объявление по идентификатору" из коллекции.  
2. Установите метод: GET.  
3. URL: `https://qa-internship.avito.com/api/1/item/:id` (нужно указать ID объявления), использовался (`abfc0fbd-7e9a-4b42-8962-d7e0ea049297`)

Статус-код: 200 OK.

```json
    {
        "createdAt": "2025-11-25 11:13:08.421129 +0300 +0300",
        "id": "abfc0fbd-7e9a-4b42-8962-d7e0ea049297",
        "name": "Andrews",
        "price": 256,
        "sellerId": 125149,
        "statistics": {
            "contacts": 99,
            "likes": 156,
            "viewCount": 24
        }
    }
]
```
