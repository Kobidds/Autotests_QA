# Autotests_QA

🛠️ Требования

Для запуска тестов необходимо установить:

- **Python 3.13.7**
- **pytest 9.0.1**
- **requests**

---

🔧 Установка

1. Убедитесь, что у вас установлен Python 3.13.7.  
   Проверить версию можно командой:
   ```bash
   python --version
   ```

2. Установите зависимости:
   ```bash
   pip install pytest
   pip install requests
   ```

---

## ▶️ Запуск тестов

Выполните в терминале команду:
```bash
python -m pytest -s
```
