

# 🐞 Баг-репорт

## Краткое описание
Сервер позволяет создавать объявления с отрицательным `sellerID` и находить их по отрицательному `sellerID`, хотя по логике идентификатор продавца должен быть **положительным целым числом** в диапазоне `111111–999999`.

---

## Шаги для воспроизведения

### Сценарий 1: Создание объявления с отрицательным `sellerID`
1. Отправить POST-запрос на `https://qa-internship.avito.com/api/1/item` с телом:
```json
   {
    "sellerID": -123456,
    "name": "Andrews",
    "price": 256,
    "statistics": {
        "likes": 156,
        "viewCount": 24,
        "contacts": 99
    }
  }
```
2. Ожидаемый результат:  
   Статус-код: 400 Bad Request

3. Фактический результат
```json
{
    "status": "Сохранили объявление - 54775235-cae3-4392-95ea-f38d613cd444"
}
 ```
### Сценарий 2: Получение всех объявлений пользователя по отрицательному `sellerID`
1. Отправить GET-запрос на `https://qa-internship.avito.com/api/1/-123456/item`
2. Ожидаемый результат
   Статус-код: 400 Bad request

3. Фактический результат

```json
{
    "createdAt": "2025-02-12 17:51:16.533872 +0300 +0300",
    "id": "8e102896-1543-4426-9cff-257ce59035bc",
    "name": "dsdsd",
    "price": 1000,
    "sellerId": -123456,
    "statistics": {
        "contacts": 10,
        "likes": 5,
        "viewCount": 100
    }
},
```
---

## Краткое описание
Сервер удаляет обьявления, но оставляет статистику объявлений.

   Статус-код: 200 OK
